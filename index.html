AI 개념 — 용어를 내 말로 바꿔 보기

    
제목을 누르면 정리가 펼쳐집니다. 펼치기 전에 스스로 한 문장으로 설명해 보고, 내 설명과 비교하세요.

  


  

    범위인공지능 · 기계학습 · 딥러닝의 관계
    

      
세 용어는 나란히 놓인 것이 아니라 포함 관계입니다. 넓은 개념 안에 좁은 개념이 들어갑니다.

      
    
        
  • 인공지능 — 사람의 지능적인 일을 기계가 하도록 만드는 분야 전체. 규칙을 사람이 직접 짜 넣는 방식도 포함됩니다.
    • 
        
  • 기계학습 — 규칙을 사람이 적어 주는 대신, 데이터에서 규칙을 스스로 찾게 하는 방법.
    • 
        
  • 딥러닝 — 기계학습 중에서 인공신경망을 여러 층으로 깊게 쌓아 학습하는 방법.
    • 
      

      
종이에 원 세 개를 겹쳐 그려 보세요. 어느 원이 가장 바깥인지 말할 수 있으면 됩니다.

    

  


  

    역사튜링 테스트가 평가하는 것
    

      
계산 속도, 기억력, 정확도를 재는 시험이 아닙니다. 사람이 대화 상대를 사람과 구별할 수 있는지를 보는 방식입니다. 즉 지능의 내부를 들여다보는 대신, 겉으로 드러난 행동만으로 판단합니다.

      
"무엇을 측정하는가"와 "무엇을 측정하지 않는가"를 함께 정리해 두면 헷갈리지 않습니다.

    

  


  

    학습지도학습 · 비지도학습 · 강화학습
    

      
    
        
  • 지도학습 — 정답(label)이 붙은 데이터로 학습. 분류, 회귀가 여기에 속합니다.
    • 
        
  • 비지도학습 — 정답 없이 데이터의 구조를 찾음. 군집화가 대표적입니다.
    • 
        
  • 강화학습 — 행동한 결과로 받은 보상을 통해 더 나은 행동을 찾아감.
    • 
      

      
구분 기준은 한 가지입니다. 정답이 주어졌는가, 보상이 주어졌는가, 아무것도 없는가.

    

  


  

    강화학습상태 · 행동 · 보상 · 환경
    

      
네 가지를 섞어서 외우면 반드시 헷갈립니다. 각각이 무엇에 대한 이름인지로 구분하세요.

      
    
        
  • 환경 — 에이전트가 놓인 세계 그 자체.
    • 
        
  • 상태 — 지금 상황을 나타내는 정보. 명사로 표현됩니다.
    • 
        
  • 행동 — 에이전트가 직접 선택해 실행하는 것. 동사로 표현됩니다.
    • 
        
  • 보상 — 행동의 결과로 되돌아오는 점수. 좋으면 +, 나쁘면 −.
    • 
      

      
판단 요령: 내가 고를 수 있으면 행동, 행동 뒤에 받는 것이면 보상, 그냥 주어져 있으면 상태입니다.

    

  


  

    생성생성 모델의 두 역할
    

      
서로 겨루는 두 신경망이 함께 학습합니다.

      
    
        
  • 생성자 — 진짜 같은 가짜 데이터를 만들어 냅니다.
    • 
        
  • 판별자 — 받은 데이터가 진짜 데이터인지 생성자가 만든 것인지 구별합니다.
    • 
      

      
파일을 저장하거나 이름을 정리하는 일은 어느 쪽의 역할도 아닙니다. 두 신경망 모두 데이터 자체를 다룹니다.

    

  







  

    
데이터를 보는 눈

    
표를 받았을 때 각 열이 어떤 성격의 데이터인지 말할 수 있어야 합니다. 숫자로 적혀 있다는 사실만으로는 아무것도 결정되지 않습니다.

  


  

    

      
범주형 · 수치형

      
범주형은 종류·등급을 나타내고, 수치형은 양을 나타냅니다. 판단 기준은 겉모습이 아니라 연산의 의미입니다.

      
더하거나 평균을 냈을 때 뜻이 통하면 수치형, 통하지 않으면 범주형입니다. 번호를 붙여 저장한 학급·등급·설문 응답은 숫자여도 범주형입니다.

    

    

      
순서가 있는 범주와 배수 해석

      
범주형 중에는 순서가 있는 것(만족도, 학점)과 없는 것(혈액형, 지역)이 있습니다.

      
순서가 있어도 "2배 만족한다"처럼 배수로 해석할 수는 없습니다. 값 사이의 간격이 같다는 보장이 없기 때문입니다.

    

    

      
이산형 · 연속형

      
수치형은 다시 셀 수 있는 값(이산형: 학생 수, 횟수)과 잴 수 있는 값(연속형: 키, 무게, 시간)으로 나뉩니다.

      
중간값이 존재할 수 있으면 연속형입니다.

    

    

      
정형 · 비정형

      
행과 열이 정해진 표 형태로 저장되면 정형 데이터입니다. 사진, 음성, 자유롭게 쓴 글은 비정형 데이터입니다.

      
표 안에 빈칸이 있다고 해서 정형이 아닌 것이 되지는 않습니다.

    

    

      
결측치

      
있어야 할 값이 비어 있는 상태입니다. 조사에서 빠졌거나 기록되지 않은 경우입니다.

      
비었다는 것과 값이 0이라는 것은 전혀 다릅니다. 0으로 채우면 평균이 왜곡되므로, 삭제하거나 평균·중앙값 등으로 대체할지 판단해야 합니다.

    

    

      
이상치

      
다른 값들과 동떨어진 값입니다. 입력 실수일 수도, 실제로 특이한 경우일 수도 있습니다.

      
단순히 가장 크거나 가장 작다는 이유만으로 이상치가 되지는 않습니다. 전체 분포에서 얼마나 벗어났는지를 봅니다.

    

  







  

    
파이썬 기본기 — 직접 값을 바꿔 보기

    
연산자는 규칙을 외우는 것보다 결과를 여러 번 만들어 보는 편이 빠릅니다. 숫자를 바꿔 가며 규칙성을 찾아보세요.

  


  

    
몫과 나머지 실험실

    
두 수를 넣고, 결과를 먼저 예측한 뒤 확인하세요. 블록 그림은 몫과 나머지가 실제로 무엇을 세는지 보여 줍니다.

    

      

      

    

    

    

    

  


  

    

      
= 와 == 는 완전히 다른 기호

      
= 는 오른쪽 값을 왼쪽 변수에 저장합니다. 왼쪽에는 반드시 변수 이름이 옵니다.

      
== 는 두 값이 같은지 비교해서 True 또는 False를 만듭니다. 저장하지 않습니다.

    

    

      
입력받은 값의 자료형

      
input()이 돌려주는 값은 언제나 문자열입니다. 계산에 쓰려면 int()나 float()로 바꿔야 합니다.

      
split()은 한 줄을 공백 기준으로 나누고, map()은 나뉜 값들에 같은 변환을 한꺼번에 적용합니다.

    

    

      
f-string의 규칙 하나

      
따옴표 앞에 f가 붙어야만 중괄호 안의 내용이 계산되어 값으로 바뀝니다.

      
f가 없으면 중괄호도 그냥 글자입니다. 중괄호 안에는 변수뿐 아니라 식도 넣을 수 있습니다.

    

    

      
연산자의 네 가지 종류

      
산술 + − * / // % **, 비교 > < >= <= == !=, 논리 and or not, 할당 = += −= 로 나뉩니다.

      
코드를 보고 "여기 쓰인 연산자는 무슨 종류인가"를 하나씩 짚는 연습을 해 두세요.

A와 B를 눌러 값을 바꾸면 세 연산의 결과가 함께 바뀝니다. 표를 외우지 말고, and는 둘 다 · or는 하나라도 · not은 뒤집기로 기억하세요.

흐름 제어 — 몇 번 실행되고, 어디로 가는가

    
조건문과 반복문에서 점수가 갈리는 지점은 문법이 아니라 실행 횟수와 실행되는 줄입니다.

  


  

    
if · elif · else 흐름 추적기

    
값을 바꾸면 어느 줄이 실행되는지 표시됩니다. 위에서부터 차례로 검사하다가 처음 참이 되는 하나만 실행하고 나머지는 아예 검사하지 않는다는 점을 확인하세요.

    

      

    

    

    

  


  

    
range 시뮬레이터

    
세 숫자를 바꿔 가며 어떤 값이 나오는지와 몇 번 반복되는지를 확인하세요. 끝 값이 포함되지 않는다는 점, 증가값이 음수면 거꾸로 간다는 점이 핵심입니다.

    

      

      

      

    

    

    

  


  

    

      
반복 횟수를 세는 방법

      
값을 전부 적은 뒤 개수를 세는 것이 가장 확실합니다. 개수가 많으면 (끝 − 시작)을 증가값으로 나눈 뒤 올림으로 확인합니다.

      
시작 값이 이미 끝을 넘어섰다면 반복은 한 번도 실행되지 않습니다.

    

    

      
들여쓰기가 범위를 정한다

      
반복문·조건문 안에 무엇이 들어가는지는 들여쓰기로 결정됩니다. 같은 줄이라도 들여쓰기가 다르면 실행 시점이 달라집니다.

      
반복 안에 있는 출력과 반복이 끝난 뒤의 출력은 결과가 전혀 다릅니다.

    

  







  

    
유형 연습 — 무엇을 묻는지 미리 겪어 보기

    
아래 열 문항은 시험 문제가 아닙니다. 시험에서 요구하는 사고 절차만 같게 만든 연습용 문항입니다. 답을 고른 뒤 풀이에 적힌 순서를 확인하세요. 답이 맞았는지보다 그 순서가 중요합니다.

④ 계단 오르기 게임

    
에너지를 써서 계단을 오르고 결과에 따라 등급을 받는 상황입니다.

    

      
동작 조건

        
    
          
  • 보유 에너지와 도전할 계단 수를 입력받습니다
    •

자주 놓치는 것들

    
아는데 틀리는 경우는 대부분 아래 항목에서 나옵니다. 시험지를 받으면 이 목록을 떠올리며 검산하세요.

  

  
    
    
  1. 끝 값은 포함되지 않는다range의 두 번째 숫자는 도달하기 직전까지입니다. 하나 더 세거나 덜 세는 실수가 가장 흔합니다.
    2. 
    
  2. 계산 전에 자료형을 확인한다입력받은 값은 문자열입니다. 변환하지 않고 더하면 숫자 덧셈이 아니라 글자 이어 붙이기가 됩니다.
    3. 
    
  3. 몫은 버림이다나눈 결과가 반올림될 것이라고 착각하지 마세요. 소수점 아래는 그대로 버려집니다.
    4. 
    
  4. 조건은 위에서부터 한 번만앞선 조건이 참이면 뒤의 조건은 검사조차 하지 않습니다. 아래쪽 조건이 참이더라도 실행되지 않습니다.
    5. 
    
  5. and와 or를 바꿔 읽지 않는다"둘 다 만족"은 and, "하나라도 만족"은 or입니다. 문제 문장에서 이 단어를 먼저 표시해 두세요.
    6. 
    
  6. 이상, 이하, 초과, 미만을 구분한다경계값이 포함되는지에 따라 부등호가 달라집니다. 경계값을 직접 대입해 검산하세요.
    7. 
    
  7. 변수 값은 덮어써진다같은 변수에 다시 저장하면 이전 값은 사라집니다. 순서를 바꾸면 결과가 달라집니다.
    8. 
    
  8. 주석은 실행되지 않는다#으로 시작하는 줄은 결과에 아무 영향을 주지 않습니다.

    10. 
    
  10. 거꾸로 찾는 문제는 대입해서 검산한다조건을 만족하는 값을 찾을 때는 후보를 하나씩 넣어 보는 편이 빠르고 정확합니다.
